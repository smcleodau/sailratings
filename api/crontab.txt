# OPS-02-05 — crontab migrated to Temporal schedules.
#
# No production ingestion runs on cron any more.  Every collection source
# (ORC, TCC, SailSys, TopYacht, ISORA, RHKYC, SailRaceHQ, cert discovery /

# health-check, refresh-views and log cleanup moved last.

# Scrapers page reads per-source health from there.
